# AZ-AWG2

## Зачем эта страница

**AZ-AWG2** управляет параллельным слоем **AmneziaWG 2.0** ([az-awg2](https://github.com/blindtechnique/az-awg2)) на активном VPN-узле: статус установки, создание и удаление клиентов, скачивание профилей. Штатные OpenVPN / WireGuard / стоковый AmneziaWG AntiZapret **не меняются**.

## Кто может пользоваться

| Действие | Администратор | Пользователь |
|----------|:-------------:|:------------:|
| Страница `/awg2` | ✓ | — |
| Создание / удаление на `/awg2` | ✓ | — |
| Создание / скачивание своих конфигов на **Конфигурации** | ✓ | ✓ (если модуль и visibility `amneziawg2`) |

## Как открыть

Боковое меню → **AZ-AWG2** (модуль `awg2` должен быть включён).

Если слой не установлен — страница покажет команду для SSH. Панель **не** запускает `install.sh` сама.

---

## Чем отличается

| | AZ-AWG2 | Стоковый AmneziaWG | AZ-WARP |
|--|---------|--------------------|---------|
| Назначение | VPN-профили AmneziaWG 2.0 (оба туннеля) | Профили AmneziaWG из AntiZapret | Точечный обход через Cloudflare WARP |
| Тип в панели | `amneziawg2` | файлы протокола `amneziawg` у `wireguard` | домены / IP, не VPN-клиент |
| Данные на диске | `/opt/antizapret-awg` | `client/amneziawg` AntiZapret | конфиги WARP |
| Вкладка Dashboard | **AmneziaWG 2.0** | **AmneziaWG** | — |

| Вкладка | Для чего |

## Пошаговые сценарии

### Включить модуль

1. **Настройки → Модули** → включите **AZ-AWG2** (`awg2`)
2. При необходимости добавьте протокол `amneziawg2` в видимость профилей для пользователей
3. Откройте **AZ-AWG2** в меню

### Установить слой на сервере

1. Откройте **AZ-AWG2**
2. Скопируйте команду установки (или обновления) с экрана
3. Выполните её по SSH на **активном** VPN-узле
4. Обновите статус на странице — должен появиться «установлен»

Команда установки:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/blindtechnique/az-awg2/main/install.sh)
```

Обновление (без смены обфускации):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/blindtechnique/az-awg2/main/install.sh) --update
```

### Создать клиента (админ)

1. Вкладка **Клиенты** на `/awg2` **или** **Конфигурации → Новый клиент → AmneziaWG 2.0**
2. Укажите имя (латиница, цифры, `_`, `-`, до 32 символов)
3. Создайте — появятся профили обоих туннелей (`antizapret` и `vpn`)

Опция **AmneziaWG 2.0** в диалоге создания на Dashboard видна только если модуль включён и слой установлен на активном узле.

### Скачать конфиг (пользователь)

1. **Конфигурации** → вкладка **AmneziaWG 2.0**
2. Скачайте нужный `.conf` (или QR, если модуль QR включён)

Стоковая вкладка **AmneziaWG** эти конфиги не показывает.

## Частые вопросы

**Нужен ли AZ-AWG2 всем?**  
Нет. Модуль opt-in (по умолчанию выключен). Включайте, если нужен слой AmneziaWG 2.0 рядом со стоком.

**Можно ли то же имя, что у WireGuard?**  
Да: уникальность `(узел, имя, тип VPN)` — `amneziawg2` и `wireguard` не конфликтуют.

**Где документация upstream?**  
[blindtechnique/az-awg2](https://github.com/blindtechnique/az-awg2)

## Будьте осторожны

- Не прерывайте установку/обновление слоя на сервере
- Не путайте вкладки **AmneziaWG** и **AmneziaWG 2.0** на Dashboard
- До среза 2a не рассчитывайте на автоматическую копию клиентов AWG2 между узлами HA
