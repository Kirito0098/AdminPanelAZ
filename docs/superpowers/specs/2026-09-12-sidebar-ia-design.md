## Контекст

Левый сайдбар сейчас в трёх группах **Операции / Конфигурация / Система**. Путаница:

- **Конфигурации** (`/`, клиенты) рядом с **Конфигурация** (протоколы / AntiZapret);
- мониторинг размазан (NOC + трафик в Операциях, Сервер + Журналы в Системе);
- Telegram и редактор файлов стоят рядом с VPN-протоколами.

Settings hub уже вынесен на `/settings` (отдельная спека). Этот дизайн — основной сайдбар.

## Цели

1. Группы = **роль в работе** оператора (не «тип страницы»).  
2. Переименовать домашний пункт **Конфигурации** → **Клиенты** (меню + заголовок дашборда).  
3. Визуально яснее разделить группы и спокойнее active/hover — в духе Better Stack / Twingate, **в текущей теме**.  
4. Не ломать URL, feature-toggles, роли, Settings hub.

## Визуал

- **Заголовки групп:** компактнее, uppercase + tracking (или эквивалент в существующих compact-классах); muted; больше воздуха / тонкий разделитель между группами.  
- **Пункты:** сохранить чип иконки + label; active = left bar + soft primary; ослабить лишний ring, если мешает.  
- **Hover:** без изменения геометрии (no jump).  
- **Header бренда + status + footer:** композиция без изменений.  
- **Mobile sheet:** те же группы и стили, что desktop.  
- Палитра: существующие CSS variables / primary — без нового «AI purple» бренда.
