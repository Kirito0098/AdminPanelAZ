# AZ-AWG2 — волна 3 (эпик)

**Дата:** 2026-08-10  
**Статус:** draft  
**Зависит от:** волны [1](2026-08-10-az-awg2-design.md) и [2](2026-08-10-az-awg2-wave2-design.md)

## Цель эпика

Закрыть ops- и client-паритет модуля AZ-AWG2: установка/обновление из панели, TTL, узкий бэкап, Telegram/Mini App, блокировки peer, детальная статистика с GeoIP панели.

## Подволны (порядок обязателен)

Срезы 1a–2c см. в [`az-awg2-epic`](2026-08-10-az-awg2-epic.md). Волна 3:

| ID | Спек | Scope |
|----|------|--------|
| **3a** | [wave3a-design](2026-08-10-az-awg2-wave3a-design.md) | Remote install/update SSE; TTL + `expires_at`; узкий backup/restore |
| **3b** | [wave3b-design](2026-08-10-az-awg2-wave3b-design.md) | Bot `/awg2`; Mini App AWG2 + configs `amneziawg2` |
| **3c** | [wave3c-design](2026-08-10-az-awg2-wave3c-design.md) | Access policy + `awg` runtime block; client deep stats + GeoIP |

Реализация: после **2c**; отдельные планы 3a/3b/3c пишутся перед стартом каждой подволны.

## Решения владельца (сводка)

| Тема | Выбор |
|------|--------|
| Структура | Три design doc + epic README |
| Remote install | SSE install + `--update`; без `--install-base` / reboot orchestration |
| TTL | Create с TTL; DB `expires_at`; expire → delete + HA `expiry.tsv` |
| Backup | Узкий tar (amnezia dir + clients + expiry), не полный upstream `awg-backup` |
| TG/Mini App | `/awg2` status admin; Mini App read-only + create/download |
| Block | Паритет temp/permanent/unblock через `awg set` |
| Deep stats | `awg_stats client` + GeoIP панели |

## Не цели эпика

- Полный upstream `awg-backup` (OpenVPN PKI, списки AntiZapret, knot)
- Обфускация / install stream внутри Telegram-бота
- Замена бота az-awg2
- Изменение AZ-WARP

## Критерий готовности эпика

Все критерии готовности 3a, 3b и 3c выполнены; регрессий волн 1–2 нет.
