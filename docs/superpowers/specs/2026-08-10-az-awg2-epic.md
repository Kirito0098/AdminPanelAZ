## Жёсткие правила на весь эпик

1. UI-имя **AZ-AWG2**, не AZ-WARP.  
2. Не писать в стоковый `/etc/wireguard` / `client/amneziawg`.  
3. Toggle `FEATURE_AWG2_ENABLED`, default **off**.  
4. До 3a: `install.sh` только по SSH-команде в UI.  
5. До 2a: HA replicate для `amneziawg2` **запрещён**.

## Критерий «готово»

Срезы 1a–4b закрыты по своим критериям (NOC/history/TG + traffic collector/limits — [noc-traffic](2026-08-11-az-awg2-noc-traffic-design.md)). Сток AmneziaWG и AZ-WARP без регрессий.
