# AZ-AWG2 Wave 3b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.  
> **Spec:** `docs/superpowers/specs/2026-08-10-az-awg2-wave3b-design.md`  
> **Depends on:** Waves 1–2; wave 3a TTL API желателен (Mini create без TTL допустим, если 3a ещё не влит).  
> **Next:** Wave 3c (`docs/superpowers/specs/2026-08-10-az-awg2-wave3c-design.md`).  
> **Patterns (образец):**  
> - Bot: `backend/app/services/telegram_bot_handlers/warper_status.py` + i18n/menu wiring рядом с AZ-WARP  
> - Shared payload: `backend/app/services/tg_mini_status.py` → `build_warper_status_payload`  
> - Mini App page: `frontend/src/tg-mini/pages/Warper.tsx` + `getTgWarperStatus` / route `/warper`  
> - Configs: `Configs.tsx` + `CreateConfigDialog.tsx` (visibility/quota + type select)

**Goal:** Встроить AZ-AWG2 в существующий Telegram-бот и Mini App: admin `/awg2` status, read-only Mini page, create/list/download/delete `amneziawg2` в Configs — без второго бота и без ops (install/обфускация) в чате.

**Architecture:** Зеркало AZ-WARP: handler `awg2_status.py` дергает shared payload (`health` + краткий `monitoring`); Mini App page `Awg2.tsx` читает те же данные через tg-mini wrappers к уже существующим `/api/awg2/health` и `/api/awg2/monitoring`; Configs расширяют type/filter/create (TTL optional из 3a). Feature toggle `awg2` гасит команду, кнопку «Ещё», Mini nav и create option.

**Tech Stack:** Existing telegram bot handlers + i18n, FastAPI tg-mini/panel routes, React tg-mini (HashRouter), pytest (handler unit), `npm run build:tg-mini` / `npm run build`.

## Global Constraints

- Один бот панели — **нет** отдельного az-awg2 бота  
- **Нет** install SSE / obfuscation / backup / peer block в TG (веб / 3c)  
- Admin only для `/awg2` и Mini page `/awg2`  
- Toggle `awg2` off → disabled message / 404 / скрытый nav / нет create option  
- Label **AZ-AWG2**; user-facing copy на русском  
- Create без TTL ок, если 3a API ещё нет; если `VpnConfigCreate.ttl` / `expires_at` есть — показать TTL select  
- Skip commits unless the user explicitly asks  
- Не рефакторить Warper/CIDR «заодно»

### Task 1: Shared AWG2 status payload + bot handler + i18n/menu wiring

**Files:**
- Modify: `backend/app/services/tg_mini_status.py`
- Create: `backend/app/services/telegram_bot_handlers/awg2_status.py`
- Modify: `backend/app/services/telegram_bot_i18n.py`
- Modify: `backend/app/services/telegram_bot_handlers/menu.py`
- Modify: `backend/app/services/telegram_bot_handlers/help.py`
- Modify: `backend/app/services/telegram_bot.py`
- Create: `backend/tests/test_awg2_telegram.py`

**Interfaces:**
- Consumes: `get_active_adapter(db).get_awg2_health()`, `.get_awg2_monitoring()` (monitoring best-effort: если not installed / error → пустой summary, не падать целиком)
- Produces `build_awg2_status_payload(db) -> dict` минимум:
  - `node_id`, `node_name`, `node_host`
  - `installed: bool`
  - `missing_components: list[str]`
  - `install_command: str | None` (из health; для текста-подсказки в боте, **без** кнопки install stream)
  - `online_count: int` (clients where `online is True`)
  - `peer_count: int` (len clients или сумма ifaces.peer_count)
  - `ifaces_summary: str` (кратко: имена iface / counts)
  - `top_traffic: list[{name, rx, tx}]` — top-3 by `(rx or 0)+(tx or 0)` desc
  - `health_error: str | None`
- Handler `handle_awg2_status(ctx, *, message_id=None)`:
  1. unlinked → `unlinked_message`
  2. not admin → `ADMIN_ONLY`
  3. toggle `awg2` off → `AWG2_DISABLED` (`MODULE_DISABLED` с именем AZ-AWG2)
  4. else format `AWG2_BODY` from payload; refresh `nav:awg2`
- i18n: `BTN_MENU_AWG2 = "🛡️ AWG2"` (или «AZ-AWG2» — уместить в inline), `MENU_ACTIONS`, `BOT_COMMANDS` entry `("awg2", "Статус AZ-AWG2 (admin)")`, `HELP_ADMIN_AWG2`, `AWG2_TITLE` / `AWG2_BODY` / `AWG2_DISABLED` / `AWG2_ERROR`
- Menu: `_ADMIN_ACTIONS` += `"awg2"`; `_awg2_visible` = admin && `is_enabled("awg2")`; в `_more_menu_row_actions` добавить `"awg2"` рядом с `"warper"`; dispatch `nav:awg2` → handler
- `telegram_bot.py`: `elif command == "/awg2": await handle_awg2_status(ctx)`

**Body text (бот) должен показывать:**
- installed? да/нет  
- если нет: missing components + install hint (`install_command` как `<code>…</code>`, без SSE)  
- online peers count  
- top-3 traffic если есть
