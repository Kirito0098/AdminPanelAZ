# AZ-AWG2 Wave 4b Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist AmneziaWG 2.0 traffic as `protocol_type=amneziawg2` and deliver WG-parity traffic limits with auto-block when traffic monitoring and AWG2 are enabled.

**Architecture:** Extend `build_status_rows` / traffic worker to append online AWG2 peers (via `fetch_awg2_peers_for_adapter`) using profiles `antizapret-awg2` / `vpn-awg2` so they never collapse into `wireguard`. Mirror WG traffic-limit columns + reconcile on `AmneziaWg2AccessPolicy`, with set/clear API and UI.

**Tech Stack:** Existing traffic collector, access_policy, client-access router, TrafficPage, pytest.

**Spec:** `docs/superpowers/specs/2026-08-11-az-awg2-noc-traffic-design.md` § Волна 4b  
**Depends on:** Wave 4a (`is_awg2_enabled`, `fetch_awg2_peers_for_adapter`, WireGuardPeer-shaped peers)

## Global Constraints

- Spec §4b only — no `/awg2` Monitoring rewrite, no new geo provider, no TG-bot limit commands
- Third protocol: never persist AWG2 as `protocol_type=wireguard`
- Profiles for collector: `antizapret-awg2` / `vpn-awg2` (NOT `-awg` — that already maps to wireguard in `protocol_type_from_profile`)
- Gate collect: `is_awg2_enabled(db)` + installed/empty via `fetch_awg2_peers_for_adapter`
- Traffic feature off (`traffic_sync_enabled`) → worker already no-ops; UI third protocol only when `isEnabled('awg2')`
- Limits: full WG parity (set/clear + `block_mode=traffic_limit` + runtime via existing AWG2 block path)
- Online peers only for collector (same as WG rows)
- Commit after each task (SDD); skip only if user forbids

from app.schemas import WireGuardPeer
from app.services.traffic.collector import build_status_rows, protocol_type_from_profile


def test_protocol_type_awg2_not_wireguard():
    assert protocol_type_from_profile("antizapret-awg2") == "amneziawg2"
    assert protocol_type_from_profile("vpn-awg2") == "amneziawg2"
    assert protocol_type_from_profile("antizapret-awg") == "wireguard"  # stock path unchanged

def test_build_status_rows_includes_online_awg2_only():
    now = datetime.utcnow()
    online = WireGuardPeer(
        interface="antizapret-awg",
        public_key="pk1",
        client_name="ivan",
        endpoint="1.2.3.4:1",
        transfer_rx=10,
        transfer_tx=20,
        latest_handshake=(now - timedelta(seconds=5)).isoformat(),
    )
    offline = WireGuardPeer(
        interface="vpn-awg",
        public_key="pk2",
        client_name="ghost",
        latest_handshake=(now - timedelta(seconds=400)).isoformat(),
    )
    rows = build_status_rows([], [], [online, offline])
    assert len(rows) == 1
    assert rows[0]["profile"] == "antizapret-awg2"
    client = rows[0]["traffic_clients"][0]
    assert client["session_kind"] == "amneziawg2"
    assert client["common_name"] == "ivan"
    assert protocol_type_from_profile(rows[0]["profile"]) == "amneziawg2"
