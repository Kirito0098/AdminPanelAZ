# AZ-AWG2 UX/UI (WARP-shell + denser clients) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align `/awg2` page chrome with AZ-WARP (Hero + OverviewCards + scrollable tabs) and densify the Clients tab cards without new backend APIs.

**Architecture:** Extract `Awg2Hero` and `Awg2OverviewCards` (including dashed layer strip) from inline `Awg2Page` markup, mirroring `WarperHero` / `OverviewCards`. Pure helpers in `awg2/utils.ts` get vitest coverage. `ClientsTab` drops the duplicate module header and tightens card chrome; business logic (create/delete/block/download) stays unchanged.

**Tech Stack:** React, TypeScript, shadcn/ui, Tailwind, vitest (frontend), existing `getAwg2Health` / `getAwg2Status` APIs.

**Spec:** `docs/superpowers/specs/2026-08-12-az-awg2-ux-ui-design.md`  
**Lazyweb:** https://www.lazyweb.com/report/lazyweb/1dfb8386-7584-40ef-b6f3-deda5565a68f/?source=create

## Global Constraints

- No new backend endpoints or schema changes
- Russian UI copy; names **AZ-AWG2** / tabs order unchanged: clients → obfuscation → monitoring → backup → help
- Mirror WARP patterns; do not import Dashboard `ConfigCard` as-is; no master-detail split-view
- Do not redesign Obfuscation / Monitoring / Backup / Help content
- Preserve install-prompt path when `!health.installed`
- Commits: only when the user explicitly asks; otherwise complete commit steps as no-op notes
- Keep existing design tokens (no purple gradients / new font stacks)

- [ ] **Step 3: Implement helpers in `utils.ts`**

Append to `frontend/src/components/awg2/utils.ts` (keep existing exports):

```ts
import type { Awg2HealthResponse, Awg2StatusResponse, Node } from '@/types'

export type Awg2Tab = 'clients' | 'obfuscation' | 'monitoring' | 'backup' | 'help'

export function awg2StatusMeta(health: Awg2HealthResponse | null) {
  if (!health) {
    return { label: 'Нет данных', variant: 'secondary' as const, dot: 'bg-muted-foreground' }
  }
  if (!health.installed) {
    return { label: 'Не установлен', variant: 'warning' as const, dot: 'bg-amber-500' }
  }
  return { label: 'Установлен', variant: 'success' as const, dot: 'bg-emerald-500' }
}

export function formatAwg2ClientCount(status: Awg2StatusResponse | null): string {
  const vpn = status?.client_counts?.vpn
  if (typeof vpn === 'number') return String(vpn)
  const az = status?.client_counts?.antizapret
  if (typeof az === 'number') return String(az)
  return '—'
}

export function formatAwg2IfacePort(iface?: string | null, port?: string | null): string {
  const parts = [iface, port].map((p) => (typeof p === 'string' ? p.trim() : '')).filter(Boolean)
  return parts.length ? parts.join(' · ') : '—'
}
```

(Merge imports with existing `Awg2HealthResponse` / `Node` import — do not duplicate.)

```tsx
export default function Awg2Page() {
  // same state: tab, health, status, loading, loadError, load()
  const nodeLabel = formatAwg2NodeLabel(health, activeNode)
  const ready = Boolean(health?.installed)

  return (
    <div className="space-y-5">
      <Awg2Hero
        health={health}
        loading={loading}
        nodeLabel={nodeLabel}
        onRefresh={() => void load()}
        onUpdated={() => void load()}
      />

      {loadError && (
        <div className="rounded-lg border border-destructive/40 bg-destructive/5 px-4 py-3 text-sm text-destructive">
          {loadError}
        </div>
      )}

      {ready && (
        <Awg2OverviewCards
          health={health}
          status={status}
          loading={loading}
          onNavigate={setTab}
        />
      )}

      {ready ? (
        <Tabs value={tab} onValueChange={(v) => setTab(v as Awg2Tab)} className="space-y-4">
          <TabsList className="flex h-auto w-full snap-x snap-mandatory gap-1 overflow-x-auto bg-muted/50 p-1 [-ms-overflow-style:none] [scrollbar-width:none] sm:inline-flex sm:w-auto sm:overflow-visible sm:snap-none [&::-webkit-scrollbar]:hidden">
            <TabsTrigger value="clients" className="shrink-0 snap-start gap-1.5 data-[state=active]:shadow-sm">
              <Users className="h-4 w-4" />
              <span>Клиенты</span>
            </TabsTrigger>
            {/* obfuscation, monitoring, backup, help — same icons; monitoring label:
                <span className="sm:hidden">Монит.</span>
                <span className="hidden sm:inline">Мониторинг</span>
            */}
          </TabsList>
          {/* TabsContent unchanged */}
        </Tabs>
      ) : !loading ? (
        <Awg2InstallPrompt health={health} activeNode={activeNode} onInstalled={() => void load()} />
      ) : null}
    </div>
  )
}
```

Move `type Awg2Tab` to import from `./utils` (or `@/components/awg2/utils`). Delete unused imports (`Server`, `Badge`, `Skeleton`, local `statusMeta`, `Awg2InstallDialog` if only used in hero now).
