> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.  
> **Spec:** `docs/superpowers/specs/2026-08-10-az-awg2-wave3c-design.md`  
> **Depends on:** Waves 1–2 (monitoring/HA/runtime apply); 3a/3b не блокируют, но UI block на тех же карточках клиентов / Dashboard.  
> **Epic done when:** 3c criteria green (closes wave 3).  
> **Patterns (образец):**  
> - Runtime: `backend/app/services/wg_runtime.py` → зеркало `awg2_runtime.py` (`awg set … peer … remove` / syncconf-restore)  
> - Policy + API: `access_policy.py` WG paths + `routers/client_access.py` `/wireguard/*` → отдельные AWG2 policy rows + `/amneziawg2/*`  
> - HA: `node_sync/policy_sync.py` `maybe_replicate_policy_op` + adapter runtime на replica; после crypto import — reapply blocked  
> - Geo: `geoip_local.lookup_geo_local` / `ip_geo._lookup_local_geo` (null без MMDB; **не** upstream bot geoip table)  
> - Stats: `awg2.get_monitoring` / `stats.db` daily + live `awg show dump` fallback  

**Goal:** Паритет temp/permanent/unblock для клиентов `amneziawg2` (runtime `awg`, отдельная policy DB) + deep stats API/UI (daily + endpoint + GeoIP панели).

**Architecture:** Не трогать `WgAccessPolicy` для имён AWG2. Новая таблица policy на `(node_id, client_name)`; service-методы зеркалят WG block/unblock, но вызывают `awg2_runtime` и conf из `/etc/amnezia/amneziawg/{AZ_IFACE,VPN_IFACE}.conf` (`services.env`). HTTP под `/api/client-access/amneziawg2/*` (admin + feature `awg2`). Deep stats — `GET /api/awg2/clients/{name}/stats` из `stats.db` / `awg_stats.py client` + dump fallback; geo только local MMDB. UI: actions на `/awg2` Clients и Dashboard card; Monitoring drawer по клику на строку.

**Tech Stack:** FastAPI, SQLAlchemy model + migrate, existing AccessPolicyService patterns, node_adapter / node_agent, React Sheet/drawer + ClientsTab/ClientActionsDialog, pytest, `npm run build`.

## Global Constraints

- **Отдельная policy** от стокового WG — никогда не писать AWG2 block в `wg_access_policy`  
- Runtime: `awg set <iface> peer <pubkey> remove`; unblock → restore из on-disk conf (syncconf/apply); **conf на диске не вырезается**  
- Ifaces/paths из `services.env` (`AZ_IFACE`/`VPN_IFACE`), default `antizapret-awg` / `vpn-awg`  
- Peer comments: поддержка `# Client = name` **и** `# name` (как `_load_peer_names` в `awg2.py`)  
- Admin only; feature toggle `awg2` gates access + stats routes  
- Geo: только `lookup_geo_local` / panel local helper → `null` если MMDB нет; **нет** нового geo-провайдера / ip-api fallback в этом endpoint (спек: null if DB missing)  
- Нет Telegram block; нет connection-history UI как у бота az-awg2  
- Нет traffic-limit / set-expiry на AWG2 access в этом срезе (TTL уже `VpnConfig.expires_at` из 3a)  
- Сток WG access без регрессий  
- Skip commits unless the user explicitly asks  
- User-facing copy на русском; label **AZ-AWG2**

### Task 1: `awg2_runtime` — collect peers + block/unblock

**Files:**
- Create: `backend/app/services/awg2_runtime.py`
- Create: `backend/tests/test_awg2_runtime.py`

**Interfaces:**
- Consumes: conf dir `/etc/amnezia/amneziawg` (injectable for tests); `services.env` → iface names; binary `awg` / `awg-quick` (зеркало strip+syncconf как `Awg2Service._sync_runtime_interface`)
- Produces (зеркало return shape `wg_runtime`):
  - `block_client_runtime(client_name: str) -> dict` — `awg set <iface> peer <pubkey> remove` for all matching peers; does **not** edit conf files
  - `unblock_client_runtime(client_name: str) -> dict` — restore peers from on-disk specs (`awg set … allowed-ips …` / PSK) **или** syncconf affected ifaces; conf remains source of truth
  - Helpers: `_peer_specs_for_client`, `_collect_client_peers`, config_files map `{iface: Path}`

**Parsing:**
- Accept `# Client = name` and bare `# name` above/beside `[Peer]` (см. `awg2._load_peer_names` / upstream overlay)
- Ignore `# PrivateKey` / `# PresharedKey` comment lines as names

**Response shape (спек):**
```json
{
  "name": "ivan",
  "online": true,
  "endpoint": "1.2.3.4:12345",
  "handshake_age_s": 12,
  "rx_life": 0,
  "tx_life": 0,
  "daily": [{"day": "2026-08-10", "rx": 0, "tx": 0}],
  "geo": {"city": "…", "country": "…", "isp": "…"} | null
```

**Data sources:**
1. Prefer `stats.db` (tables `peers`/`totals`/`daily`, `origin='awg2'`) — same DB path helpers as monitoring; optional subprocess `awg_stats.py client <name>` only if parsing DB is insufficient

3. Endpoint IP → strip port / brackets → `lookup_geo_local(ip)` (via `ip_geo` local-only helper). If MMDB not loaded → `geo: null` (do **not** call ip-api for this endpoint)
