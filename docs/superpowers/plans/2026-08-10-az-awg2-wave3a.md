# AZ-AWG2 Wave 3a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.  
> **Spec:** `docs/superpowers/specs/2026-08-10-az-awg2-wave3a-design.md`  
> **Depends on:** Waves 1–2 (2c monitoring landed).  
> **Next:** Wave 3b (`docs/superpowers/specs/2026-08-10-az-awg2-wave3b-design.md`).  
> **Patterns:** Warper SSE `GET /warper/updates/stream` (`backend/app/routers/warper.py`, `WarperService.iter_update_stream_events`); frontend `openWarperUpdateStream`.  
> **Upstream:** [blindtechnique/az-awg2](https://github.com/blindtechnique/az-awg2) — `install.sh` flags `--no-bot` `--preset` `--template` `--fp` `--update` (**never** `--install-base`); `client-awg.sh add … --ttl`; `expiry.tsv` (`name\tsvc\tunix_ts`); full `awg-backup.sh` includes OVPN/knot/lists/`stats.db` — **do not** copy that scope.

**Goal:** Panel SSE install/update of the AWG2 layer (no base/reboot orchestration), TTL clients with `VpnConfig.expires_at` + expire job, and a **narrow** AWG2-only backup/restore tab.

**Architecture:** Mirror Warper update SSE for `install.sh` / `--update` behind a per-node lock; extend `Awg2Service.add_client` + configs create with `--ttl` and DB `expires_at`; background tick reconciles `expiry.tsv` / expire-check and deletes DB rows; backup tar is a stricter cousin of HA `export_state_archive` (amneziawg + clients + `expiry.tsv` only).

**Tech Stack:** FastAPI `StreamingResponse`, existing `Awg2Service` / node_adapter / node_agent, SQLAlchemy migrate column, React EventSource + tabs, pytest.

## Global Constraints

- SSE install/update only; **no** `--install-base`, **no** reboot orchestration from the panel  
- Default install flags include `--no-bot`; preset/template non-interactive  
- If AntiZapret base missing → SSE `error` + SSH hint for base install (not panel-run)  
- One concurrent install/update lock per node  
- TTL: create optional `ttl` (`30m`/`2h`/`6h`/`7d`/…); DB `vpn_configs.expires_at`; upstream truth `/opt/antizapret-awg/expiry.tsv`  
- Expire job must delete CLI peers/files **and** `VpnConfig` row (no orphans)  
- Narrow backup tar: `amneziawg/`, `clients/`, `awgstate/expiry.tsv`, `MANIFEST` — **exclude** OVPN PKI, `/root/antizapret/config`, knot, stock `client/`, venv, `stats.db`  
- After restore on primary: `apply_awg2_runtime` + HA sync (wave 2 machinery)  
- Label **AZ-AWG2**; feature toggle `awg2` still gates routes  
- Skip commits unless the user explicitly asks  
- Docs/UI copy in Russian where user-facing

**Interfaces:**

  - `iter_install_stream_events(mode, **opts) -> Iterator[dict]` — acquire lock (fail with error event if busy), check base for install mode, spawn process, yield log lines, `done` with return_code, always release lock
