# AZ-WARP

## Зачем эта страница

**AZ-WARP** направляет трафик **отдельных сайтов и сервисов** через Cloudflare WARP — это другой способ обхода блокировок, точечный, для конкретных доменов (ChatGPT, Gemini и др.).

## Кто может пользоваться

Только **администратор**.

## Как открыть

Боковое меню → **AZ-WARP**.

Если модуль не установлен — страница предложит установку.

---

## Вкладки

| Вкладка | Для чего |
|---------|----------|
| **Домены** | Список сайтов, которые идут через WARP |
| **IP-подсети** | Диапазоны IP для WARP-маршрутизации |
| **Мониторинг** | Статус, трафик, логи WARP |
| **Настройки** | Режим выхода, сеть, sing-box, обслуживание и обновление AZ-WARP |

Панель поддерживает AZ-WARP **1.5.0**. Функции, которых нет на старой версии AZ-WARP, отвечают «Обновите AZ-WARP на узле (нужна версия ≥ …)»; если устарел node agent панели на VPN-узле — «Обновите node agent панели на узле».

## Настройки

### Режим выхода

| Режим | Что указать |
|-------|-------------|
| **WARP** | Источник ключа: авто, system, wgcf, root или сгенерировать новый. Ниже — список найденных ключей с отметкой «Текущий» |
| **Slave (Shadowsocks)** | Ссылка `ss://` донора (AZ-WARP 1.5.0+) или вручную Host / Port / SS-key |
| **WireGuard** | Файл `.conf` на узле |
| **VLESS** | Ссылка `vless://` |
| **Hysteria2** | Ссылка `hy2://` или `hysteria2://` |
| **OpenVPN** | Файл `.ovpn` на узле; если сервер требует логин — логин и пароль. Сохранённый логин можно забыть кнопкой «Забыть логин» |

Для VLESS / Hysteria2 / OpenVPN в статусе показывается сервер выхода (без секретов).

### Сеть WARP

- **FullVPN** — WARP-резолвинг доменов и для клиентов полного VPN (vpn-*)
- **Автопатч DNS при загрузке** — служба `warper-autopatch` переприменяет патч kresd после перезагрузки
- **Fake-подсеть** — по умолчанию `10.224.0.0/16`. Не используйте `198.18.0.0/15` (AntiZapret) и `172.16.0.0/12` (Docker). После смены клиентам нужно переподключиться

### sing-box

MTU и уровень логов; статус службы и версия; автозагрузка; запуск / остановка / перезапуск и **Обновить sing-box** до последней версии.

### Обслуживание

**Запустить resync** — переприменяет FORWARD, ipset, маршруты и патч kresd. Узел делает это сам раз в 10 минут и после ночной пересборки AntiZapret; вручную — после doall.sh или смены режима встроенного WARP AntiZapret. Здесь же — подсети клиентов AntiZapret / VPN.

### Обновление AZ-WARP

Если обновление с 1.4.x на 1.5.0 было запущено старым кодом и не завершилось, появится предупреждение и бейдж «Обновление не завершено». Нажмите **Завершить обновление** — панель повторит `warper update`.

### Встроенный WARP AntiZapret

С AZ-WARP 1.5.0 встроенный WARP AntiZapret (`ANTIZAPRET_WARP` в **Конфиг AntiZapret**) больше не блокирует AZ-WARP — они работают вместе. Если встроенный WARP включён, на странице AZ-WARP показывается подсказка: после doall.sh нажмите **Запустить resync**. Предупреждение «Устаревший node agent на узле» означает, что агент панели на VPN-узле старый и всё ещё блокирует AZ-WARP при `ANTIZAPRET_WARP=y` — обновите агент.

## Пошаговые сценарии

### Включить AZ-WARP

1. Откройте **AZ-WARP**
2. Если видите предложение установить — следуйте инструкции на экране
3. Включите переключатель в верхней части страницы

### Добавить сайт для WARP

1. Перейдите на вкладку **Домены**
2. Нажмите добавить домен или импортируйте список
3. Есть готовые списки для Gemini, ChatGPT — можно включить одной кнопкой
4. Нажмите **Синхронизировать**, если нужно применить на сервер

### Проверить, работает ли WARP

1. Вкладка **Мониторинг** — статус службы и трафик
2. Вкладка с логами — ошибки подключения, если что-то не так

### Диагностика проблем

В разделе **Doctor** (если есть на странице) — автоматическая проверка типичных проблем с WARP.

## Кнопки (вкладка Домены)

| Кнопка | Что делает | Когда использовать |
|--------|------------|-------------------|
| **Добавить домен** | Один сайт в список WARP | Для точечного добавления |
| **Импорт** | Загрузка списка доменов | Много сайтов сразу |
| **Встроенные списки** | Gemini, ChatGPT и др. | Быстрый старт |
| **Обновить списки из репозитория** | Скачать свежие встроенные списки AZ-WARP | Когда сервис сменил домены |
| **Синхронизировать** | Применить список на сервер | После изменений |
| **Удалить** | Убрать домен из WARP | Сайт больше не нужен через WARP |

## IP-подсети: авто-резолв

Блок **Авто-резолв доменов в IP-маршруты** на вкладке **IP-подсети**:

- **Авто-резолв** — AZ-WARP сам резолвит домены из списка и добавляет их IP в маршруты
- **Резолвить сейчас** / **С принудительной синхронизацией** — выполнить резолв немедленно
- **Очистить RESOLVED** — удалить автоматически добавленные IP одного домена или весь блок

Блок **Применённые маршруты**: **Показать маршруты** — что реально стоит в ядре; **Снять все маршруты** (файл подсетей не меняется — маршруты вернутся при следующей синхронизации).

## Частые вопросы

**Чем WARP отличается от обычной маршрутизации?**  
Обычная маршрутизация (CIDR) работает по спискам провайдеров. WARP — отдельный канал через Cloudflare для выбранных доменов.

**Нужен ли WARP всем?**  
Нет, это опциональный модуль. Включайте, если нужен доступ к конкретным зарубежным сервисам.

**WARP и Конфиг AntiZapret — связаны?**  
Да, в **Конфиг AntiZapret** есть встроенный WARP AntiZapret-VPN (режимы None / All / Domain / Custom — см. [antizapret-config.md](antizapret-config.md#встроенный-cloudflare-warp)). AZ-WARP — отдельный модуль с детальным управлением доменами, режимами выхода и мониторингом; с версии 1.5.0 они совместимы.

---

## Будьте осторожны

- Отключение WARP может нарушить доступ к сайтам, которые шли через него
- Массовый импорт доменов — проверьте список перед синхронизацией
- Установка и обновление WARP требуют времени — не прерывайте процесс
