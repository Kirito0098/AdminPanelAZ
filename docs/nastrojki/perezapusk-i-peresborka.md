# Перезапуск и пересборка

## Зачем этот раздел

Операции над **самой панелью** без обновления кода из Git: пересборка интерфейса и перезапуск сервиса `adminpanelaz`.

## Кто может пользоваться

Только **администратор**. Вкладка скрыта, если модуль `panel_ops` выключен.

## Как открыть

**Настройки** → **Перезапуск и пересборка**.

---

## Пошаговые сценарии

### Пересобрать интерфейс

Нужно после ручного изменения файлов frontend на сервере или если UI не обновился после деплоя. **Не** подтягивает новый код с GitHub — для этого есть [Обновления](obnovleniya.md).

1. Откройте **Перезапуск и пересборка**
2. В карточке **Пересборка интерфейса** нажмите **Пересобрать и перезапустить**
3. Подтвердите действие
4. Дождитесь завершения: `npm run build:all`, затем перезапуск `adminpanelaz`

Панель будет недоступна после сборки. Не запускайте одновременно с **Обновлением** из Git.

### Только перезапустить панель

1. В карточке перезапуска подтвердите действие
2. Сервис `adminpanelaz` перезапустится через systemd

Эквивалент на сервере:

```bash
sudo systemctl restart adminpanelaz
```

---

## Частые вопросы

**Чем отличается от «Обновлений»?**  
**Обновления** — `git pull` и новая версия. **Пересборка** — только сборка уже лежащего на диске frontend.

**Чем отличается от «Диагностики»?**  
**Диагностика** — smoke-тесты и runbook. Этот раздел — restart/rebuild.

**Ошибка «уже выполняется»**  
Дождитесь окончания текущей задачи обновления или пересборки; параллельно их нельзя.

---

## Будьте осторожны

- Пересборка на слабом сервере может занять долго — не прерывайте процесс
- Клиенты панели кратковременно потеряют доступ при перезапуске
