# Перезапуск и пересборка

## Зачем этот раздел

Операции над **самой панелью** без обновления кода из Git: пересборка интерфейса и перезапуск сервиса `adminpanelaz`.

## Кто может пользоваться

Только **администратор**. Вкладка скрыта, если модуль `panel_ops` выключен.

## Как открыть

**Настройки** → **Перезапуск и пересборка**.

---

## Пошаговые сценарии

### Переустановить интерфейс

Нужно, если UI не обновился после обновления или деплоя. **Не** подтягивает новый код с GitHub — для этого есть [Обновление панели](obnovleniya.md).

1. Откройте **Перезапуск и пересборка**
2. В карточке **Переустановка интерфейса** нажмите **Переустановить и перезапустить**
3. Подтвердите действие
4. Дождитесь завершения: готовая сборка для текущего коммита из GitHub (канал `frontend-builds`), затем перезапуск `adminpanelaz`. Если сборки нет — интерфейс собирается на сервере (`npm run build:all`), это дольше

Во время переустановки панель продолжает работать со старым интерфейсом. Новая версия встаёт на место двумя переименованиями; если что-то не удалось, остаётся прежний интерфейс. Ответ `503` («Интерфейс пересобирается, повторите через несколько секунд») бывает, только если интерфейс ещё ни разу не собран. После переустановки панель перезапускается и несколько секунд недоступна. Не запускайте одновременно с **Обновлением панели**.

### Только перезапустить панель

1. В карточке **Перезапуск панели** нажмите **Перезапустить панель**
2. Подтвердите — сервис `adminpanelaz` перезапустится через systemd

Перезапуск применяет изменения из `.env`; незавершённые фоновые задачи прервутся.

Эквивалент на сервере:

```bash
sudo systemctl restart adminpanelaz
```

или `sudo adminpanelaz --restart` — меню дополнительно предупредит, если интерфейс собран до последнего обновления кода.

## Частые вопросы

**Чем отличается от «Обновления панели»?**
**Обновление панели** — новая версия из Git, зависимости, сборка и перезапуск. **Пересборка** — только сборка уже лежащего на диске frontend и перезапуск.

**Чем отличается от «Проверки работы»?**
**Проверка работы** — автоматическая диагностика. Этот раздел — перезапуск и пересборка.

**Ошибка «уже выполняется»**
Дождитесь окончания текущей задачи обновления или пересборки; параллельно их нельзя.

---

## Будьте осторожны

- Пересборка на слабом сервере может занять долго — не прерывайте процесс
- Пользователи панели кратковременно потеряют доступ при перезапуске
