# Настройки панели

Раздел **Настройки** в боковом меню — здесь настраивают профиль, доступ в панель, VPN, сервер и работу самой панели. Подразделы собраны в пять групп: **Личное**, **Доступ**, **VPN**, **Сервер**, **Панель**.

---

## Кто что видит

| Группа | Подраздел | Администратор | Пользователь |
|--------|-----------|:-------------:|:------------:|
| Личное | Мой профиль | ✓ | ✓ |
| Доступ | Пользователи панели | ✓ | — |
| Доступ | Защита входа | ✓ | — |
| VPN | Выдача VPN-профилей | ✓ | — |
| VPN | Обслуживание VPN | ✓ | — |
| Сервер | Адрес сайта и HTTPS | ✓ | — |
| Сервер | Резервные копии | ✓ | — |
| Сервер | Нагрузка и уведомления | ✓ | — |
| Панель | Уведомления в панели | ✓ | — |
| Панель | Разделы панели | ✓ | — |
| Панель | Обновление панели | ✓ | — |
| Панель | Перезапуск и пересборка | ✓ | — |
| Панель | Проверка работы | ✓ | — |

**Пользователи панели** — это доступ в саму панель (логин и роль), а не абоненты VPN; абоненты ведутся в разделе **Абоненты**.
