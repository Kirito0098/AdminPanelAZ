# Выдача VPN-профилей

## Зачем этот раздел

Настройка того, **как клиенты получают VPN-файлы**: профили скачиваются из панели и через клиентский портал, а здесь настраивается выдача файлов маршрутизации для роутеров и публичная ссылка на них.

## Кто может пользоваться

Только **администратор**.

## Как открыть

**Настройки** → **Выдача VPN-профилей**.

---

## Что можно настроить

| Блок | Простыми словами |
|------|------------------|
| **Скачивание маршрутов** | Готовые конфиги Keenetic, MikroTik и TP-Link после настройки маршрутизации: скачать из панели или отдать клиенту ссылкой |
| **Ссылка для клиента без входа в панель** | Включает публичную ссылку на route-файлы. По умолчанию выключено. Если выключено — файлы скачиваются только авторизованным пользователям панели |

Профили клиентов (`.ovpn`, WireGuard, AmneziaWG) скачиваются на странице **Пользователи** и в Telegram; постоянная ссылка на подписку настраивается в разделе [Подписка](../podpiska.md#клиентский-портал).

---

## Пошаговые сценарии

### Отдать клиенту маршруты для роутера

1. Откройте **Выдача VPN-профилей**
2. Настройте маршрутизацию, если ещё не сделали этого
3. В блоке **Скачивание маршрутов** нажмите **Скачать** — файл сохранится на компьютер
4. Кнопка **Ссылка** копирует адрес: клиент скачает файл без входа в панель

Ссылка работает, только если включён переключатель **Ссылка для клиента без входа в панель**.

### Включить публичные файлы маршрутизации

1. Найдите блок **Скачивание маршрутов**
2. Включите **Ссылка для клиента без входа в панель**, если нужно раздавать файлы AntiZapret по прямой ссылке
3. Используйте только если понимаете риски — файлы станут доступны без пароля

---

## Частые вопросы

**Ссылка не открывается у клиента**  
Проверьте, что переключатель **Ссылка для клиента без входа в панель** включён и что панель доступна по HTTPS с устройства клиента.

**Где клиент скачивает конфиг?**  
Профили — на странице **Пользователи** кнопкой **Скачать** на карточке клиента, через Telegram ([Telegram.md](../Telegram.md)) или по постоянной ссылке клиентского портала (кнопка **Ссылка**, раздел [Подписка](../podpiska.md#клиентский-портал)). Маршруты для роутеров — здесь, в **Выдаче VPN-профилей**.

**Где включается этот раздел?**  
В **Настройки → Разделы панели**, модуль **Выдача VPN-профилей** (ключ `qr_downloads` — исторический). Выключенный модуль убирает скачивание профилей из панели; сам раздел с маршрутами виден при включённом модуле OpenVPN.

---

## Будьте осторожны

- Публичные route-файлы без HTTPS — не рекомендуется
- Включённая публичная ссылка открывает маршруты любому, у кого есть адрес: не публикуйте её в открытых чатах
