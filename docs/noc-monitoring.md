# NOC Мониторинг

## Зачем эта страница

**NOC Мониторинг** показывает картину «здесь и сейчас»: кто подключён к VPN, откуда заходит, сколько трафика идёт, работают ли службы на сервере.

## Кто может пользоваться

Только **администратор**. У ролей «пользователь» и «наблюдатель» раздел скрыт: на странице видны IP и сессии всех клиентов.

## Как открыть

Боковое меню → **NOC Мониторинг**.

Если у вас несколько VPN-серверов — в шапке выберите **активный узел** или переключитесь в режим **«Все узлы»**, чтобы видеть сводку по каждому.

| Блок | Зачем |
|------|-------|
| **Лента инцидентов** | Сработавшие алерты, offline-узлы, ошибки CIDR и неактивные службы |

| **Подключения** | Список клиентов: IP, город, провайдер, скорость, длительность; фильтры узел/город/ISP/протокол; отключение OVPN |

| **Панель** | Нагрузка на сервер, где работает сама панель (только для администратора) |

## Подключения через прокси-узел

Если модуль **Прокси-узлы** включён и клиент заходит на VPN через известный прокси-узел, в списке **Подключения** панель может показать **домашний IP** клиента (и геолокацию по нему) и пометку «через прокси».

Если связь «порт прокси → домашний IP» временно недоступна, в адресе остаётся IP прокси, а рядом — пометка «через прокси · IP не восстановлен». Учёт трафика и Telegram-сводки от этого не меняются. Полная схема: [proxy-nodes.md](proxy-nodes.md); узлы: [uzly.md](uzly.md); агент: [proxy-agent.md](proxy-agent.md).

То же обогащение по endpoint действует и для пиров **AWG 2.0** (AmneziaWG 2.0), когда модуль AZ-AWG2 включён.

## AmneziaWG 2.0 (AZ-AWG2) на NOC

Если модуль **AZ-AWG2** включён (**Настройки → Модули**) и слой установлен на узле, NOC показывает **AWG 2.0** как отдельный протокол рядом с OpenVPN и WireGuard — не смешивает его со стоковым WG:

- в **сводке** и на карточках узлов — счётчик онлайн AWG 2.0 (handshake моложе ~3 минут);
- в списке **Подключения** — пиры с бейджем **AWG 2.0**, фильтр протокола;
- на **графиках** истории — третья серия AWG 2.0;
- в **Telegram**-сводках (текст и еженедельная картинка) — текущие и пиковые значения AWG 2.0.

Если модуль выключен, страница и сводки выглядят как раньше (без UI AWG 2.0). Если слой на узле не установлен или недоступен — счётчики AWG 2.0 нулевые, без ошибок. Подробнее о модуле: [awg2.md](awg2.md).

## Пошаговые сценарии

### Посмотреть, кто сейчас онлайн

1. Откройте **NOC Мониторинг**
2. Перейдите на вкладку **Подключения**
3. Включите фильтр **«Только онлайн»**
4. При необходимости введите имя клиента в поиск

### Обновить данные

- Страница обновляется автоматически примерно каждые 30 секунд
- Нажмите кнопку обновления вручную, если нужны свежие цифры прямо сейчас

### Посмотреть несколько серверов

1. В шапке переключите режим на **«Все узлы»**
2. Сводка и таблицы покажут данные по каждому узлу

## Кнопки и фильтры

| Элемент | Что делает | Когда использовать |
|---------|------------|-------------------|
| **Только онлайн** | Показывает только активные подключения | Когда нужен список «кто в сети сейчас» |
| **Поиск** | Фильтр по имени клиента | При большом числе пользователей |
| **Фильтр протокола** | OpenVPN / WireGuard / **AWG 2.0** (если модуль включён) / все | Когда интересует один тип VPN |
| **Узел / город / ISP / длительность** | Дополнительные фильтры списка | При большом числе сессий на NOC |
| **Показать по узлам** | HA-режим без дедупликации | Когда нужно видеть сессию на каждом физическом сервере |
| **Отключить** | Завершить OpenVPN-сессию | Быстрая реакция с NOC |
| **Обновить** | Загрузить данные заново | После изменений на сервере |

## Telegram-сводки

Ежедневная и еженедельная сводки в Telegram настраиваются **лично** каждым администратором: **Настройки → Личные → NOC сводка — расписание**. Время — по часовому поясу профиля; пока не задано — системное расписание (UTC). Подробнее: [Telegram.md](Telegram.md#расписание-noc-сводок).

При включённом **AZ-AWG2** в тексте сводки и на еженедельной PNG появляется третий протокол **AWG 2.0** (текущие и пиковые concurrent по истории подключений). Пока модуль выключен — сводки без AWG 2.0, как раньше.

## Частые вопросы

**Город и провайдер — это точно?**  
Нет, это приблизительная геолокация по IP-адресу. Обычно верны город и интернет-провайдер, но возможны ошибки.

**Почему клиент «онлайн», хотя он выключил VPN?**  
Иногда статус обновляется с небольшой задержкой. Подождите автообновления или нажмите **Обновить**.

**Как сделать геолокацию без интернета?**  
Администратор может загрузить локальные базы GeoIP — см. [GeoIP.md](GeoIP.md).
